# Think Deeper — launch checklist

## Before publishing
- Open `index.html` locally and review desktop + mobile width.
- Open the full Essay 001 page and check paragraph spacing, section hierarchy and references.
- Confirm the public wording on the About page is the anonymity/AI disclosure you want.
- Confirm @ThinkDeeperHQ is the final X handle.
- Do not add a custom domain until the free GitHub Pages version is working.

## GitHub Pages
1. Create a new public GitHub repository called `think-deeper`.
2. Upload all files and folders from this package to the repository root.
3. Commit to `main`.
4. Open Settings → Pages.
5. Under Build and deployment select `Deploy from a branch`.
6. Choose `main` and `/ (root)`.
7. Save.
8. Wait for the Pages deployment to complete, then open the generated `github.io` URL.

## After the site is live
- Test homepage navigation.
- Test Essay 001 on desktop and phone.
- Test About and Corrections.
- Share the live URL with nobody yet.
- We do one final live-site QA pass.
- Then prepare the first X launch post.
